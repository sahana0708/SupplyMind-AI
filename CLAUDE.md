
# SupplyMind AI

## Project Overview
SupplyMind AI is an AI-powered enterprise operations
and supply chain recovery platform.

It detects supply chain disruptions, investigates
business impact and recommends recovery actions.

## Technology Stack
- Python
- FastAPI
- PostgreSQL
- React
- TypeScript
- Claude API
- MCP
- Temporal
- Pandas
- NumPy
- Docker

## Main Modules
1. Watcher Agent
2. Commander Agent
3. Financial Risk Engine
4. Supplier Recommendation Engine
5. MCP Server
6. Workflow Orchestration
7. Human Approval System
8. Analytics Dashboard
9. Audit Logging

## Architecture Rules
- Keep frontend and backend separate.
- Use modular Python code.
- Use PostgreSQL for persistent data.
- Use Python for financial calculations.
- Use Claude for language understanding
  and recovery recommendations.
- Require human approval before external actions.
- Never hardcode passwords or API keys.

## Development Rules
- Implement one feature at a time.
- Explain the purpose of every major file.
- Do not delete existing work without permission.
- Write tests for important functionality.
- Run tests after implementation.
- Report files created and modified.
- Provide exact commands to run and test features.
- Do not claim functionality works unless tested.
